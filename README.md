# Md. Tasnimul Hassan - Personal Portfolio

This is the personal academic portfolio for Md. Tasnimul Hassan, an undergraduate student in Electrical and Electronic Engineering at BUET.

## Overview

This website is built with a modern web stack designed to be lightweight, static, and performant:
- **Framework**: React / Vite
- **Styling**: Tailwind CSS
- **Data**: JSON-driven content management
- **Animations**: Framer Motion (motion/react)
