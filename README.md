# Md. Tasnimul Hassan - Personal Portfolio

This is the personal academic portfolio for Md. Tasnimul Hassan, an undergraduate student in Electrical and Electronic Engineering at BUET.

## Overview

This website is built with a modern web stack designed to be lightweight, static, and performant:
- **Framework**: React / Vite
- **Styling**: Tailwind CSS
- **Data**: JSON-driven content management
- **Animations**: Framer Motion (motion/react)

## Development

To run the project locally:

```bash
# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production (Cloudflare Pages, Vercel, Netlify, etc.)
npm run build
```

## Content Management

All textual content is managed via structured JSON files located in `src/data/`. To update the website's content, simply edit the respective `.json` files.
